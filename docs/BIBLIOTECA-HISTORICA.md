# Biblioteca histórica

A biblioteca é organizada por contrato e pregão.

Cada lote importado registra:

- tipo de dado;
- fonte;
- arquivo;
- contrato;
- primeiro/último timestamp;
- registros recebidos;
- registros inseridos;
- duplicados;
- diagnóstico.

A proveniência permite saber meses depois de onde vieram os dados usados em uma pesquisa.

Sessões consideradas de baixa qualidade são excluídas das comparações por padrão, mas continuam disponíveis para auditoria.
